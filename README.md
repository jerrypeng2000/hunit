# 换算通 HUnit

面向跨境电商从业者的浏览器扩展：长度、长×宽、长×宽×高三种维度实时换算，自动算面积、体积、体积重，输出可直接粘贴到 Amazon / eBay / 独立站的上架格式。

## 核心能力

- 1D 长度：mm / cm / m / in / ft / yd 双向换算，快捷值 0.25m / 0.5m / 1m / 2m / 3m / 6ft / 10ft
- 2D 长×宽：长宽同时换算，自动算面积
- 3D 长×宽×高：长宽高同时换算，自动算体积、体积重（5000 / 6000 / 139 / 166 可切换）、计费重
- 重量：g / kg / lb / oz 双向换算
- 汇率：USD / CNY / EUR / GBP / JPY / AUD / CAD 实时汇率，缓存 10 分钟，异常自动用缓存
- 成本定价器：采购成本 + 目标利润 + 平台佣金 → 建议售价（免费可用）
- 海关编码：关键词查询 HS 编码、税率、退税率、申报要素（数据来源 www.hsbianma.com）
- 常用表：尺寸、重量、汇率、定价、海关编码五类数据统一管理（免费 10 条，会员无限）
- 智能解析：粘贴 `12x6x1`、`30*15*2cm`、`3.3ft`、`12"` 自动填充
- 划词换算、右键换算、快捷键 Alt+U
- 首页 = 最大化窗口：弹窗底部“最大化窗口”一键展开为完整页面，设置也在首页
- 会员管理：一键订购包月，退订下月生效，当前包月到期前仍可使用
- 计费标准：余额包月到期自动续费；余额不足自动停止并在应用内提醒充值；
  免费额度、包月价格、自动续费均可由 AjkAPI 后台按应用配置（见 `docs/计费接口标准.md`）

## 支持的浏览器

- Google Chrome
- Microsoft Edge
- 360 安全浏览器 / 360 极速浏览器（Chromium 内核）

## 安装方法

1. 下载 `release/hunit-v1.2.0-chromium.zip`。
2. 解压到固定文件夹。
3. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   - 360 安全浏览器：`se://extensions`
4. 打开“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
6. 固定扩展图标，按 `Alt+U` 或点击图标打开。

## 连接 AjkAPI

1. 打开扩展设置。
2. 保持服务器地址 `https://ajkapi.9zos.com`。
3. 应用标识填写 `hunit`。
4. 在 AjkAPI 控制台生成 Access Token，填入设置。
5. 点击“测试连接”。

未连接 AjkAPI 时，扩展在本地试用模式下提供每天 10 次换算。

## 使用方法

### 尺寸换算

- 选择 1D / 2D / 3D 模式，输入即出结果；
- “上架格式”输出 `12 x 6 x 1 inches` 或 `30.5 x 15.2 x 2.5 cm`；
- “物流/箱规”输出体积、体积重、计费重，自动判断泡货 / 重货；
- 粘贴 `12x6x1`、`30*15*2cm`、`3.3ft`、`12"` 自动解析；
- 批量换算：每行一个尺寸，会员一次转换多行。

### 划词与右键

- 网页中选中 `12cm`、`3.5in`、`500g`、`$20` 等文字会出现“换算”按钮；
- 右键菜单“用换算通 HUnit 换算选中内容”直接出结果。

## 从源码构建

```bash
cd extension
npm install
npm run build
```

构建产物在 `extension/dist/`，代码已混淆，可作为浏览器扩展安装包。

## 校验

`release/SHA256SUMS.txt` 提供发布包 SHA-256 校验值。

## 隐私说明

- 所有单位、面积、体积、体积重计算都在本地完成；
- 只有额度、会员和计费信息会调用 AjkAPI；
- 汇率通过公开接口获取，不上传换算内容。
